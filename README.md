## About the course

Most people type a request, read the answer and try again. This course replaces that loop with a method. You take a prompt apart into goal, context, instructions, constraints, examples and output format, and you learn which part to change when a response goes wrong.

From there you build up: structured frameworks and templates, test sets that tell you whether a prompt really improved, meta-prompts that get the model to critique and rewrite its own instructions, and multi-agent workflows where each agent has a role, a handoff and a structured output.

The course suits analysts, consultants, knowledge workers, product and marketing practitioners, researchers and technical professionals who already use large language models at work.

## Learning outcomes

By the end of the course you will be able to:

1. Create nuanced and strategic prompts that optimise AI model performance, combining different methodologies to generate innovative and effective prompts.
2. Explain the principles, structural components and paradigms of effective prompt engineering.
3. Apply structured prompting frameworks to construct clear, testable and reusable prompts.
4. Assess the quality, performance and potential impact of generative AI models across the domains and applications in which they are used.
5. Design self-improving prompt systems using meta-prompting techniques for iterative refinement.
6. Develop multi-agent prompt workflows using role-based delegation and cognitive task decomposition.
