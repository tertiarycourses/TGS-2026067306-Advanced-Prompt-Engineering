## About the course

This intermediate course turns intuitive prompting into a repeatable method. Learners define success before running a prompt, combine methods deliberately, test representative cases, isolate failures and evaluate the quality, performance and potential impact of model outputs. Six connected labs use Meridian Fulfilment, a fictional Singapore SME. All data is synthetic.

## Learning outcomes

1. Explain the principles, structural components and paradigms of effective prompt engineering, and differentiate between the prompting approaches available for a given task.
2. Create nuanced and strategic prompts that optimise AI model performance, combining different methodologies to generate innovative and effective prompts.
3. Apply structured prompting frameworks to construct clear, testable and reusable prompts, and refine them through iterative testing and systematic debugging.
4. Assess the quality, performance and potential impact of generative AI models across the domains and applications in which they are used.
5. Design self-improving prompt systems using meta-prompting techniques for iterative refinement and quality control.
6. Develop multi-agent prompt workflows using role-based delegation and cognitive task decomposition, incorporating structured output schemas and error handling.
